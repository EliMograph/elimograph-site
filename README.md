# elimograph — сайт-портфолио

Цифровой кубик Рубика: тёмный корпус, клетки — светящиеся стеклянные панели цветов граней, вокруг мягкая аура. Пустые клетки — просто цветные; клетка с работой показывает картинку в рамке цвета своей грани. Кнопка «Solve the cube» собирает кубик. Vite + Three.js, без фреймворка.

## Запуск
```
npm install
npm run dev        # http://localhost:5173
npm run build      # готовый сайт в dist/
npm run preview    # посмотреть dist/ локально
```
Посмотреть сайт с тестовыми работами (только в dev): `http://localhost:5173/?works=/dev-fixtures/works.json`.

## Как добавить работу
Код трогать не нужно. Работа — это файлы в `public/works/` и строка в `public/works.json`.

**Быстрый способ** (нужен ffmpeg). Скрипт сжимает видео для веба, делает постер и беззвучное превью на 4 с и сам дописывает строку:
```
npm run add-work -- "../clients/acme/renders/acme_launch_9x16_v2.mp4" --title "Acme" --client "Acme Inc." --type "Launch video"
```
Ключ `--start 2.5` выбирает секунду, с которой берутся постер и превью (по умолчанию 1).

**Вручную.** Положи файлы в `public/works/` и добавь объект в `public/works.json`:
```json
[
  {
    "title": "Acme",
    "client": "Acme Inc.",
    "type": "Launch video",
    "format": "9:16",
    "video": "works/acme.mp4",
    "poster": "works/acme.jpg",
    "preview": "works/acme-preview.mp4"
  }
]
```
- Обязательно только `video`. Без `poster` кадр для клетки берётся из видео. Без `preview` при наведении играет само видео, без звука.
- Порядок в файле = порядок на кубике: первая работа встаёт в центр передней грани, дальше по одной на каждую видимую грань.
- Пустые клетки — цветные наклейки. Всего на кубике 54 клетки.
- Видео для сайта: H.264, до 1080 px по короткой стороне, до ~10 МБ. Скрипт делает это сам.

## Контакты и палитра
`public/site.json`: `email` (кнопка Contact → mailto), `x` (ссылка на X) и `palette`.

Палитры: `ink` (основная), `classic`, `soft`, `paper` (описаны в `src/palettes.js`). Любую можно посмотреть без правок: `?palette=ink` в адресе.

## Публикация на Vercel (бесплатно)
1. Залей папку `portfolio/` в репозиторий GitHub (корнем репозитория может быть сама `portfolio/`).
2. На vercel.com → Add New → Project → выбери репозиторий. Если `portfolio/` лежит внутри большого репозитория, укажи Root Directory = `portfolio`.
3. Vercel сам увидит Vite (`vercel.json` уже настроен): Build `npm run build`, Output `dist`. Нажми Deploy.
4. Новая работа = коммит с файлами и строкой в `works.json`; Vercel пересоберёт сайт сам.

Без GitHub: `npx vercel` в папке `portfolio/` (вход в аккаунт Vercel нужен один раз).

Лимиты бесплатного тарифа: один файл до 100 МБ, трафик ~100 ГБ в месяц. Поэтому видео сжимаем, исходники не выкладываем.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка: прелоадер, шапка, герой, список работ, плеер |

## Поведение
- Кубик стартует перемешанным и медленно вращается. Если его не трогать, каждые ~4,5 с поворачивается случайный слой (не больше ~30 ходов в истории, чтобы сборка шла быстро).
- «Solve the cube» проигрывает ходы назад: кубик собирается за ~3–4 с и коротко вспыхивает. Потом кнопка становится «Shuffle». Собранный кубик стоит, пока его не тронут.
- Скролл — обычный, страница сразу едет вниз. Кубик сначала выглядывает снизу первого экрана, при прокрутке поднимается в центр, потом уходит вверх и немного уменьшается; под ним идёт список.
- Кнопка Contact выдвигает снизу панель с email (ссылка и «Copy»).
- Рендер без постобработки (60 кадров); если компьютер не успевает, сайт сам снижает разрешение кубика, а не дёргается.
- Перетаскивание по клетке поворачивает её слой, после отпускания слой доворачивается до 90°. Перетаскивание по пустому месту вращает кубик.
- Наведение на работу: кубик замирает, рамка клетки светится, играет беззвучное превью, рядом подсказка. Клик открывает ролик со звуком на весь экран, закрытие — Esc.
- Курсор системный: не отстаёт и не пропадает.
- Телефон: кубик крутится свайпом по горизонтали, вертикальный свайп прокручивает страницу; ниже обычный список работ.
- `prefers-reduced-motion`: без автоповоротов и изгиба.
